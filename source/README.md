# 五阵破军源码

神话三国题材的网页卡牌构筑游戏，当前版本 v0.5.3。

需要 Node.js 20.19 或更高版本。在本目录依次运行：

```text
npm ci
npm run dev
```

正式构建：`npm run build`，产物位于本目录的 `dist`。
规则与流程检查：`npm run verify`。

仓库根目录保存已经构建好的 GitHub Pages 网页。修改源码后，需要重新构建并更新根目录的网页文件。
图片和字体位于 `public`，授权说明随资源保留。
系统说明、项目介绍、复盘与截图位于仓库的 `portfolio` 和 `screenshots` 目录。
