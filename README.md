# 五阵破军 · 神话三国

系统策划作品｜可玩网页 Demo｜v0.5.3

一款以五格布阵为核心的单人卡牌构筑游戏。玩家通过人物、相邻兵器、职业匹配和战术组合伤害，再用战后成长与军市投资培养牌组。

## 项目内容

- 五格布阵、相邻装备与职业匹配，配套实时伤害预览和结算总览。
- 三套起始构筑、60 种实装战斗卡、九种三阶锦囊和三大关十八战。
- 战后随机强化、金币重抽、军市消费与首领阵位规则。
- 桌面与手机浏览器布局，新手演武，以及当前浏览器的自动存档和导入导出。

## AI 协作

AI 用于辅助代码实现、规则核对和美术生成；系统取舍围绕布阵、成长、经济、界面信息和特殊情况裁定展开。通过自动对局、存档回放和界面检查核对实际行为。
自动验证用于规则与流程检查；当前资料不代表已完成真人乐趣与真机性能验证。

## 试玩

建议先体验新手演武，再进行首战选卡、强化与首次军市。
玩家进度保存在当前设备、浏览器和网站地址下；本版本不提供账号或云存档。
